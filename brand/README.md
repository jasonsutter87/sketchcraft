# SketchCraft brand

The builder beaver: an engraved black-ink beaver with a carpenter's pencil in
its orange teeth, on a violet tile. Beavers are nature's push/pull builders, and
the pencil is the sketch in SketchCraft. The mark sits in the Craft family
(engraved animals on saturated tiles).

## Files

| File | Use |
| --- | --- |
| `beaver.py` | The source. Every file below is generated by it: `python3 brand/beaver.py` |
| `mark.svg`, `mark-512.png` | The mark on its rounded tile (web, docs, listings) |
| `app-icon.svg`, `app-icon-1024.png` | macOS app icon: 1024 canvas, 824 tile, 100 margin, soft shadow. Feed the PNG to `npx tauri icon` in `app/` |
| `favicon.svg` | The 16-32 px cut: flat shapes, a steep pencil (flat, it reads as a duck's bill) |
| `logo.svg` | Mark and wordmark |
| `banner.svg`, `banner.png` | README header |

After changing `beaver.py`, regenerate the PNGs:

```sh
python3 brand/beaver.py
rsvg-convert -w 1024 -h 1024 brand/app-icon.svg -o brand/app-icon-1024.png
rsvg-convert -w 512 brand/mark.svg -o brand/mark-512.png
rsvg-convert -w 1800 brand/banner.svg -o brand/banner.png
cp brand/favicon.svg app/public/favicon.svg
(cd app && npx tauri icon ../brand/app-icon-1024.png)   # then delete android/, ios/, Square*/StoreLogo
```

## Color

| Name | Hex | Use |
| --- | --- | --- |
| Violet | `#6f4df0` | The tile, primary buttons, the selected tool |
| Violet ink | `#4a2fc4` | Accent text and links on paper |
| Violet lite | `#bfb2ff` | Highlights, the pencil's eraser |
| Ink | `#15131c` | Text and linework |
| Graphite | `#4b4658` | Quiet text |
| Paper | `#f6f1e4` | Backgrounds |
| Card | `#fffdf7` | Panels |
| Rule | `#d8cfb8` | Borders, drafting grid |
| Pencil yellow | `#f2c230` | One accent at a time: the pencil, the active workspace mark |
| Beaver orange | `#e8892b` | The teeth only |

Ink on violet is only 3.5:1: put **white** text on the violet tile, ink on paper.

## Type

- **Bricolage Grotesque**: display and interface.
- **IBM Plex Mono**: commands, measurements, code.

Both are on Google Fonts under the SIL Open Font License. Until they're
installed, the app and the generated art fall back to Avenir Next / the system
sans and SF Mono / Menlo.

## In the app

The **Workshop** skin (`app/src/skins.ts`) is this palette and type, and is the
default. The top bar logo is the favicon cut.
